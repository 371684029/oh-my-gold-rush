## 2. P0 级问题详述（数学与统计硬伤，v2.4 第一阶段必改）

### F01｜「最大回撤 (MaxDD)」实际算的是「相对起点亏损 (`minRet`)」，严重掩盖中途腰斩风险

- **代码位置**：
  - `web/forecast-engine.cjs:328, 481-492`
  - `web/forecast-longterm.cjs:666-676, 707, 809-813`
  - `src/utils/prob-path-forecast.ts:260-267`（追踪了 `peak`，但用了算术差 `v - peak` 而非几何回撤 `(1+v)/(1+peak) - 1`）
- **现状实现**：
  ```js
  // forecast-longterm.cjs:666-676
  let minRet = 0;
  for (let h = 1; h <= months; h++) {
    const rawPct = ((closes[m + h] - startPrice) / startPrice) * 100;
    const scaled = rawPct * volScale;
    if (scaled < minRet) minRet = scaled;
    if (rawPct < rawMinRet) rawMinRet = rawPct;
  }
  ```
- **违背的金融学原理**：
  - **最大回撤（Maximum Drawdown, MDD）** 的严格金融定义是**区间内任意高点到其后最低点的最大几何跌幅**：
    $$\text{MDD} = \min_{0 \le s < t \le H} \left(\frac{P_t}{P_s} - 1\right)$$
  - 代码中的 `minRet` 只是「相对买入价 $P_0$ 的最大浮亏」（Underwater Loss from Entry），完全忽略了先大涨再暴跌的路径回撤。
  - **实证后果**：2008-10 买入持有 5 年至 2013-10，金价先从 $730 涨至 2011 年 $1,900，随后暴跌至 $1,200（真实 **Peak-to-Trough MaxDD ≈ -35%**），但因为从未跌破起点 $730，系统在相似案例表里赫然显示 **`最大回撤 +0.0%`**，严重低估长期持有心理承受压力！
  - `prob-path-forecast.ts:265` 的 `dd = v - peak` 同样存在数学错误：若从 `+100%` 跌回 `+50%`，算术差是 `-50%`，而真实几何回撤是 `(1.5 / 2.0) - 1 = -25%`。
- **v2.4 修复方案**：
  1. 统一定义路径级纯函数 `computePathMaxDrawdown(pricePath)`（使用相对净值 $V_h = P_h / P_0$，`runningPeak = Math.max(runningPeak, V_h)`，`dd = (V_h / runningPeak) - 1`）。
  2. 若需同时向定投用户展示「低于当前买入成本的最大浮亏」，应**拆分为两个独立字段**：`maxDrawdownPct`（峰谷最大回撤）与 `maxUnderwaterPct`（相对现价最大浮亏），绝不混称。

### F02｜FHS 波动率归一化直接乘在算术累计收益率上，破坏几何复利且错误放大漂移项

- **代码位置**：
  - `src/utils/prob-path-forecast.ts:210`
  - `web/forecast-engine.cjs:325-326`
  - `web/forecast-longterm.cjs:670-671, 784`
- **现状实现**：
  ```js
  const rawPct = ((closes[m + h] - startPrice) / startPrice) * 100;
  const scaled = rawPct * volScale; // volScale 最大可达 2.2x（日线）或 1.4x（长期）
  ```
- **违背的金融学原理**：
  1. **破坏价格非负性与复利对称性**：资产价格服从几何演化 $P_t > 0$。对简单累计收益率直接乘 `volScale`，在波动放大期可能产生 `< -100%` 的负金价（迫使 `forecast-longterm.cjs:784` 打上 `Math.max(-55, p10)` 的硬编码补丁）。
  2. **把期望漂移（Drift）也按波动率同比例放大**：标准 **Filtered Historical Simulation（Barone-Adesi, Giannopoulos & Vosper, 1999）** 缩放的是**去均值后的标准化对数收益率残差（Innovations）**，而不是把历史趋势收益 $\mu$ 也乘以 $\sigma_0 / \sigma_d$！
     - 当 2026 年处于高波动状态（`volScale = 1.4`）时，历史一段 5 年 `+100%` 的牛市会被凭空拉长成 `+140%`——**高波动反而被算法当成了「更高期望收益」**，这完全违背风险-收益基础理论。
- **v2.4 修复方案**：
  - 在**单步对数收益率**层做标准去均值 FHS：
    1. 历史窗口单步对数收益 $r_{d+k} = \ln(P_{d+k} / P_{d+k-1})$，估计该区间均步漂移 $\hat{\mu}$ 或全样本无条件长期漂移 $\mu_0$；
    2. 仅对残差做波动缩放：$\tilde{r}_{d+k} = \mu_0 + \text{clamp}(\sigma_0 / \sigma_d, L, U) \cdot (r_{d+k} - \hat{\mu}_d)$；
    3. 按指数复利还原路径累计收益：$\tilde{R}_h = \exp\!\left(\sum_{k=1}^{h} \tilde{r}_{d+k}\right) - 1$。
  - 天然保证价格严格为正（$\tilde{R}_h > -100\%$），不再需要 `Math.max(-55, p10)` 补丁，且波动率放大只拓宽扇形宽度，不再扭曲中位数漂移。

### F03｜TIPS 与 10Y 美债因子使用「相对百分比偏离」，在零利率附近出现除零爆炸与久期失真

- **代码位置**：
  - `src/indicators/quant-score.ts:174-194`（`us10yFactor`、`tipsFactor`）
- **现状实现**：
  ```ts
  // quant-score.ts:189-192
  const base = ma20 ?? prev;
  const dev = base !== 0 ? ((cur - base) / Math.abs(base)) * 100 : cur * 100;
  const score = clamp(50 - dev * 0.8, 10, 90);
  ```
- **违背的金融学原理**：
  - 股票/商品价格是**比率尺度（Ratio Scale）**，适合算百分比变化 $\Delta P / P$；但**利率（尤其是可正可负的实际利率 TIPS）是区间尺度（Interval Scale）**，金融工程中债券久期（Duration）与黄金对实际利率的敏感度均线性依赖于**基点绝对变化 $\Delta y$（bps）**，绝不是 $\Delta y / |y|$！
  - **灾难场景**：2020–2022 年 TIPS 频繁穿越 `0%`。当 `MA20 = +0.02%`、当日 `cur = +0.12%`（仅变动区区 +10 bps），`dev = (0.12 - 0.02) / 0.02 × 100 = +500%`，因子分直接砸穿下限 `10`；而当 `MA20 = 2.50%` 时，同样 +10 bps 变动 `dev` 仅为 `+4%`，得分 `46.8`——**同样的 10 bps 利率冲击，信号强度相差 125 倍！**
  - 注：`mid-term-outlook.ts:154` 已经正确使用了 `changeBp = (latest - prev) * 100`，仅 `quant-score.ts` 遗留了这一错误。
- **v2.4 修复方案**：
  - `tipsFactor` 与 `us10yFactor` 统一改为**基点偏离**（`devBp = (cur - ma20) * 100`）或**滚动标准差 Z-score**（`(cur - ma20) / rollingStd60`），例如每偏离 +25 bps 扣 15 分并平滑映射到 `[10, 90]`，彻底消除零点奇异。

### F04｜分位数线性加权混合 + 双重计入宏观漂移 + 概率与分位口径自相矛盾

- **代码位置**：
  - `web/forecast-engine.cjs:447-457, 493-498, 520-526`
  - `web/forecast-longterm.cjs:740-753, 768-782, 830-840`
- **现状实现**：
  ```js
  const driftPct = rawTiltNorm * 0.14 * sigma0 * Math.sqrt(h);
  const mix = (c, u) => (1 - shrinkageWeight) * c + shrinkageWeight * u + driftPct;
  ```
- **违背的概率论与统计学原理**：
  1. **混合分布的分位数 ≠ 分位数的线性加权**：设混合分布为 $F_{\text{mix}} = (1-\lambda) F_{\text{cond}} + \lambda F_{\text{uncond}}$。数学上 $Q_{F_{\text{mix}}}(q) \ne (1-\lambda) Q_{F_{\text{cond}}}(q) + \lambda Q_{F_{\text{uncond}}}(q)$。当条件分布与无条件分布均值分离时，对分位数做线性平均会**系统性低估尾部宽度（低估 P10 风险与 P90 空间）**。（注：`src/utils/prob-path-forecast.ts` 已正确采用混合权重池求分位，但 Web 端两套引擎退回了分位线性平均。）
  2. **宏观因子双重计入（Double Counting）**：条件权重 `weights` 已经用 TIPS / DXY / CPI / 估值 Z-score 筛选过历史相似宏观路径，随后又把同样由这些指标算出的 `compositeScore` 转成额外平移项 `driftPct` 强行叠加到 5 条分位线上，构成重复计分与主观平移。
  3. **内部概率自相矛盾**：
     - `upEndProb`（期末收涨概率）与 `touchProb`（结构位触达概率）**只用了条件权重 `weights`，没有做向无条件分布的收缩 $\lambda$**；在 `forecast-longterm.cjs:746` 中 `upEndProb` 甚至连 `driftPct` 都没加，而 `p50` 加了收缩与漂移——会导致页面同时出现「P50 为负，但收涨概率 > 50%」的逻辑悖论！
     - `touchProb`（`forecast-engine.cjs:523`）把期末 $h=H$ 的总漂移 `endDrift` 加到了中途某一天发生的 `e.maxRet`/`e.minRet` 上，时间尺度错配。
- **v2.4 修复方案**：
  1. 废弃「分位线性平均」，统一在**样本权重层**构造收缩混合权重：$w_i^{\text{mix}} = (1-\lambda) \frac{w_i}{\sum w_j} + \lambda \frac{1}{N}$。
  2. 所有输出指标（`P10/P25/P50/P75/P90`、`maxDdP50/P90`、`upEndProb`、`beatCpiProb`、`touchProb`）全部从**同一个混合权重分布**计算，保证 100% 概率自洽（$P(\text{end}>0) > 50\% \iff P50 > 0$）。
  3. 移除额外叠加的启发式 `driftPct`；三面评分仅作用于特征核权重或展示归因，不再事后平移分位数。

### F05｜校准偏移与情景概率在极小样本（`n >= 3`）即启动硬修正，且混淆「打分」与「胜率」

- **代码位置**：
  - `src/utils/calibration-adjust.ts:15-34`
  - `src/utils/scenario-probability.ts:21-57`
- **现状实现**：
  - `calibration-adjust.ts`：`sampleSize >= 3` 即生效；计算 `offset = actualProbPct - midScore`，且非对称截断至 `[-8, +3]`。
  - `scenario-probability.ts`：`filled.length >= 3` 即用原始频率替代默认概率，且以固定阈值 `±1.0%` 划分涨跌基准情景。
- **违背的统计学与计量金融原理**：
  1. **分数 ≠ 概率（Scale Mismatch）**：在近有效金融市场中，5 日方向预测即便是最顶级的量化信号，胜率通常也只在 **54%–60%**，绝不会达到 `75%–85%`。把 0–100 综合强度分（如 `midScore = 75`）直接等价为「5 日上涨概率应为 75%」，必然导致 `actualProbPct - midScore` 长期为 `-15% ~ -20%`，触发持续的 `-8` 惩罚；再叠加 `[-8, +3]` 非对称截断，人为制造了**永久性看空偏移**！
  2. **极小样本过拟合**：`n = 3` 时二项分布 95% 置信区间宽达 `[21%, 94%]`，此时做偏移修正或将情景概率设成 `85% / 0% / 15%` 纯属拟合噪音。这正是 `ROADMAP-FINENG.md §7` 记录的 **情景 Brier 技巧分为 `-0.2`（不如盲猜历史基率）** 的根源。
  3. **固定 ±1% 阈值未做波动率标准化**：在低波年（年化 10%，5 日 1σ ≈ 1.4%）±1% 含义合理；在 2026 高波年（年化 28%，5 日 1σ ≈ 4.0%），±1% 仅 0.25σ，几乎所有 5 日收益都会掉出基准情景，导致基准情景概率系统性崩溃。
- **v2.4 修复方案**：
  1. **校准层重构**：改用 **Platt Scaling / 等渗回归（或单调逻辑映射）** 将 0–100 分映射为校准后上涨概率 $\hat{p} \in [0.35, 0.65]$，**不再直接用胜率去减原始分**；最小生效样本量提高至 $N \ge 30$（非重叠等价样本 $N_{\text{eff}} \ge 15$），且截断区间对称。
  2. **情景概率重构**：引入 **Dirichlet/Beta 经验贝叶斯收缩**（向全样本历史基率收缩，等效先验强度 $k = 15$），并将三情景阈值改为波动率自适应边界（例如 $\pm 0.5 \cdot \sigma_{5d}$），同时验证 OOS Brier Skill Score 转正（`BSS > 0`）。

## 3. P1 级问题详述（金融学建模失真，v2.4 第二阶段改造）

### F07｜波动率因子无条件将「高波动 = 看多避险」写死，且计算的是收盘价绝对变动而非真实波幅 ATR

- **代码位置**：`src/indicators/quant-score.ts:197-216`（`volatilityFactor`，权重 5%）
- **现状与问题**：
  1. 计算 `sum(|C_t - C_{t-1}| / C_{t-1}) / 14`，忽略日内高低价跳空，并非 Wilder 定义的 True Range ATR。
  2. 将 `atrPct > 0.5%` 线性映射为**看多（最高 70 分）**。金融学中**波动率是无方向的风险尺度，而非单向看多 Alpha**：在流动性危机/保证金追缴期（2020-03、2013-04 暴跌、高位获利回吐闪崩），黄金波动率飙升恰恰伴随剧烈下跌。把它放进方向分，不仅在暴跌时给出错误看多信号，还与仓位模块的 `volToScalar`（高波动降仓）正面打架。
- **v2.4 修复方案**：
  - 将 `volatility` 的方向权重置为 **`0`**（退出方向评分，彻底收口至 Risk & Gates 层的仓位缩放与扇形带宽），并将计算升级为使用 `High / Low / Close` 的标准 14 日 Wilder ATR%（缺高低价时注明 Close-to-Close Realized Vol）。

### F08｜RSI(14) 与布林带 %B 在同一线性打分中逻辑自相矛盾，且未区分趋势/震荡体制

### F13｜2000–2026 样本存在单边超级牛市偏差，且 5 年重叠窗口的独立样本量 `N_eff` 被严重高估
