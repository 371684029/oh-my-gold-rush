## 1. 用户要什么（问题陈述）

用户希望得到 **「尽可能有依据、准确、符合金融学逻辑的黄金未来趋势预测图」**，形态是 **双层概率分布扇形图（Fan Chart）**，而不是：

- 单条「必到某价」的点位曲线；
- 顶/底 + 倒计时式算命；
- 忽略波动率环境、拿低波行情去套高波危机的假区间。

| 维度 | 用户直觉 | 产品化表述（v2.0） |
|------|----------|--------------------|
| 纵轴 | 相对今天涨跌多少 % | 全图统一以 **决策日收盘价 `spot` 为 0% 锚点**（历史实线与未来扇形在 `(今天, 0%)` 无缝衔接） |
| 横轴 | 还要等多久 | **未来有效交易日**序号（与 `forward-return` 单一来源对齐，非自然日） |
| 分布形态 | 核心区 + 极端风险区 | **P25–P75 深色核心带 + P10–P90 浅色外沿带 + P50 中位线 + 无条件 FHS P50 对照虚线** |
| 波动适配 | 行情大起大落时区间要跟着放大 | **FHS（滤波历史模拟）**：按样本日 $\sigma_d$ 归一化、按今日 $\sigma_0$ 还原 |
| 实用风险 | 中途最惨可能亏多少 / 压力支撑在哪 | 同步给出 **路径内最大回撤（MaxDD P50/P90）** 与 **结构位触达概率**（布林上下轨 / MA20） |

**一句话**：**按今日波动率尺度归一化、分短/中视野独立条件化后的黄金未来 5/20 个交易日经验概率扇形图与路径风险面板。**

## 2. 为什么必须从 v1 骨架升级到 v2.0（复盘已发现问题）

v1 初版代码虽然已经跑通基础链路，但对照金融工程与仓库实测（`goldrush-stats-latest.json`、`OPTIMIZATION-2026-11.md`）暴露了 **4 项统计/金融学硬伤** 与 **4 项工程缺陷**：

| 类别 | v1 缺陷 | v2.0 修正方案 |
|------|---------|---------------|
| **条件错配** | 5 日和 20 日共用 LLM `overall.score` 分桶（实测 5 日命中仅 45.5% ≈ 基准），违背 `HORIZONS.md` 中期只吃慢变量原则 | **5 日 / 20 日彻底分轨**：5 日用 `quantScore` + 波动率 + 标准化相似日；20 日用 `mid_term_score` + 宏观 Regime |
| **无波动率调节** | 低波期与高波期原始收益混算分位，导致低波虚宽、高波频频击穿 P10 | 引入机构标准 **FHS 波动率归一化**（$\hat{r}_d(h) = r_d(h) \cdot \sigma_0 / \sigma_d$） |
| **小样本 + 重叠 + 泄漏** | 只抽百余天报告、5 日强行等待满 20 日路径、连续重叠日虚增 $n$、未校验 `endDate <= asOf` | 严格校验 **`pathEndDate <= asOf`**；引入**多年度客观行情特征池**；去重叠并输出 **$N_{\text{eff}}$**；小样本向无条件 FHS **收缩（Shrinkage）** |
| **相似度失真** | `scenario-similarity` 中 `vix`/`geo` 恒正导致余弦相似度虚高；缺少路径 MaxDD 与触达概率 | 改用 **Z-score 加权欧氏距离 + 同 Regime 优先**（权重倾斜 TIPS/DXY/趋势/波动）；新增 **P25–P75、MaxDD 分位、结构位触达概率** |
| **工程 Bug** | ① 历史线按 60 日前归零、未来按今日归零 → 断崖跳空；② `meta.svgRel` 写死 `-latest.svg` 覆盖历史报告；③ `MA20` 硬编码为压力位 + SVG 右侧截断 + 深色底与浅色网页割裂；④ `path.ts` 硬编码 `gateActionable: true` 绕过门禁 | ① 历史段统一按 `spot` 归零；② `svgRel` 永久指向带日期文件名；③ 动态判定支撑/压力 + 适配浅色 Web 主题 + 留足标签区；④ CLI 接入真实 `data-quality-gate` |

## 3. 核心算法规格（v2.0 锁定）

### 3.1 统一坐标与历史段

- **历史段**：最近 60 个有效 `london_close`，纵轴统一为相对今日收盘的涨跌百分比：
  $$\text{pctFromSpot}(t) = \left(\frac{\text{close}(t)}{\text{spot}} - 1\right) \times 100\%$$
- 当 $t = \text{asOf}$ 时严格为 `0%`，直接与未来段 `(0, 0%)` 衔接。

### 3.2 短 / 中双视野独立条件化（彻底解耦）

| 视野 | 主条件变量 | 宏观/波动约束 | 样本池来源 |
|------|-----------|---------------|-----------|
| **H = 5（短期主图）** | `quantScore`（量化分）+ 标准化特征近邻 | 优先同波动率分位段 / 同宏观 Regime | 历史报告 + 多年度客观行情特征池（只需满足 `endDate(d, 5) <= asOf`） |
| **H = 20（中期副图）** | `mid_term_score`（中期慢变量分）+ 宏观 Regime | 优先同宏观阶段（如 `real_rate_headwind`） | 历史中期记录 + 多年度客观慢变量特征池（满足 `endDate(d, 20) <= asOf`） |
| **长期 1/3/5 年** | **不出概率路径扇形** | 保持配置向（见 `LONG-TERM-OUTLOOK.md`） | — |

### 3.3 FHS 波动率归一化 + 距离加权 + 小样本收缩

对视野 $H \in \{5, 20\}$：

1. **严格防前视泄漏**：仅纳入满足 `pathEndDate(d, H) <= asOf` 且 `validClose` 完整的历史起点 $d$。
2. **FHS 波动率缩放**：
   - 计算每个样本日 $d$ 与今日的 20 日实现日波动率（或 ATR%）$\sigma_d, \sigma_0$（做安全上下限夹紧，如缩放比 $\sigma_0/\sigma_d \in [0.4, 2.5]$ 防极端除零放大）；
   - 将每条历史路径逐日缩放至今日波动尺度：$\hat{r}_d(h) = r_d(h) \cdot \frac{\sigma_0}{\sigma_d}$。
3. **相似日距离与去重叠权重**：
   - 使用 **Z-score 加权欧氏距离**（替代等权余弦相似度），核心权重倾斜黄金经济学锚：**实际利率（TIPS）趋势、美元（DXY）偏离、均线趋势结构、波动率分位、CFTC/资金流**；
   - 对时间上高度重叠的连续样本日做**去重叠衰减 / 最小间隔聚类**，计算 Kish 有效独立样本数：
     $$N_{\text{eff}} = \frac{(\sum w_i)^2}{\sum w_i^2}$$
4. **经验贝叶斯收缩（Empirical Bayes Shrinkage）**：
   - 同时计算全历史客观池的 **无条件 FHS 基准分布** $Q^{\text{uncond}}_\tau(h)$；
   - 设收缩权重 $\lambda = \frac{K}{N_{\text{eff}} + K}$（如 $K = 15$；若 v2.1 OOS 评估显示条件 CRPS 未跑赢基准则自动提高 $\lambda$）；
   - 最终分位（$\tau \in \{0.10, 0.25, 0.50, 0.75, 0.90\}$）：
     $$Q^{\text{final}}_\tau(h) = (1 - \lambda)\, Q^{\text{cond}}_\tau(h) + \lambda\, Q^{\text{uncond}}_\tau(h)$$
   - 当条件样本极稀缺时平滑退化为无条件 FHS 基准，消除 `n=10~15` 时分位剧烈跳变。

### 3.4 路径级风险与结构位首达概率

对同一批 FHS 缩放后的路径集合 $\{\hat{r}_d(1..H)\}$，除逐日分位外同步输出：

- **路径内最大回撤分位**：每条样本路径 $d$ 的 $\text{minRet}_d = \min_{1 \le h \le H} \hat{r}_d(h)$，取加权 **P50（中位不利回撤）** 与 **P10（90% 不利尾部回撤，记 `maxDdP90`）**；
- **终点收涨概率**：加权统计 $\mathbb{P}(\hat{r}_d(H) > 0)$；
- **结构位动态分类与触达概率**：
  - 按 `pctFromSpot >= 0 ? 'resistance' : 'support'` 动态标注布林上轨、MA20、布林下轨；
  - 统计路径中任意一日触及该相对水平的历史频率（`touchProb5d` / `touchProb20d`）。

### 3.5 门禁与降级策略（Gates 层硬规则）

- **全入口统一走 `data-quality-gate`**：无论是 `analysis --md` 还是独立命令 `goldrush path`，均须读取真实门禁状态，严禁硬编码 `gateActionable: true`。
- **降级梯度**：
  - `full`：$N_{\text{eff}} \ge 25$ → 正常条件 FHS 扇形；
  - `sparse`：$8 \le N_{\text{eff}} < 25$ → 条件 FHS 扇形 + 明显收缩 + 图例提示「有效样本偏少，已向波动率基准收缩」；
  - `unconditional_only`：条件样本不足但历史行情池充足 → 展示无条件 FHS 波动率基准扇形并明确注明；
  - `history_only`：全库历史行情不足 10 日 → 仅画历史走势；
  - 红档（无有效金价或门禁红灯）：若无有效金价则 `no_spot` 不出图；若仅门禁红灯，图例强制提示「仅供研究参考，不构成操作建议」。

## 4. 明确不做什么（反模式红线）

| 反模式 | 原因 |
|--------|------|
| 对外 KPI =「点位/路径猜中率」 | 黄金短期近随机游走；KPI 应为覆盖率校准、CRPS 技巧分、仓位纪律与回撤控制 |
| 用 LLM 直接编造未来曲线或主观调宽扇形 | 破坏可审计与可复现；LLM 仅做文字叙事与三情景解释 |
| 用路径扇形直接覆盖 `recommendPosition` 仓位公式 | v2.0 仍在 Signals + Explain 层；仓位以短期操作建议与风险约束仓位为准 |
| 在未通过 Walk-forward 基准检验前宣称「高精度预测」 | 必须先跑赢无条件 FHS 随机游走基准 |
| 上 LSTM / 深度学习单线预测 | 样本量不足、黑盒不可审计、极易过拟合 |

## 6. 验收标准（v2.0 完成定义）

1. **数学与金融卫生**：
   - 单测覆盖：历史回放零前视泄漏（修改 `asOf` 之后未来价格不影响输出）、FHS 波动率缩放单调性（$\sigma_0$ 翻倍则扇形带宽线性放大）、连续重叠日 $N_{\text{eff}} < n$、小样本自动向无条件 FHS 收缩、5 日与 20 日条件轨道独立。
2. **工程与视觉**：
   - `history` 末点严格为 `0%`，历史实线与未来扇形平滑衔接无跳空；
   - `meta.svgRel` 指向带日期的 SVG 文件，历史文章不被新报告覆盖；
   - `MA20` 按相对位置动态区分 `support`/`resistance`，SVG 标签无截断、视觉与浅色 Web 主题统一；
   - `goldrush path` 遵守真实 `data-quality-gate`。
3. **测试与构建**：
   - `npm run lint` 与 `npm test` 全部通过；
   - 浏览器实测首页与文章页 5日/20日概率路径面板渲染完整、无控制台报错。
