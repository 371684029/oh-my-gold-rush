## 1. 用户要什么（问题陈述）

用户希望得到 **「预测以后的趋势」且能画出来**，形态偏好是 **概率分布折线图**，而不是：

- 单条「必到某价」的预测曲线；
- 绝对美元刻度的点位承诺；
- 顶/底 + 倒计时式算命。

更贴近需求的理解是：

| 维度 | 用户直觉 | 产品化表述 |
|------|----------|------------|
| 纵轴 | 涨跌百分比 | 相对 **决策日收盘价** 的累计涨跌幅 **%**（T+0 = 0%） |
| 横轴 | 还要等多久 | **未来有效交易日** 序号（与 `forward-return` 一致，非自然日） |
| 「分布」 | 不是一条线，而是一坨可能 | 每个未来日 **H**，用历史样本画出 **P10 / P50 / P90**（或 25–75% 带）的 **累计收益 %** |
| 「折线」 | 要能看图 | 至少 **3 条分位折线** + 可选 **中间填充带**；左侧接 **历史累计 % 实线** |
| 顶 / 底 | 大概在哪 | 用分位线触及或接近 **结构带 %**（布林/MA）时的读法，**不叫「精确顶底」** |

**一句话**：**条件于「今天像历史上的哪一天」之后，未来 H 日金价累计涨跌 % 的经验分位扇形图（Fan Chart）。**

## 2. 与 GoldRush 产品边界对齐

### 2.1 做什么

- **Explain + Signals**：可视化 **历史统计路径分布**，强化「区间 / 风险 / 节奏」，服务定投与仓位纪律。
- **纯本地可复现**：数字来自 `gold_prices` + 报告/特征库，**不**用 LLM 画线。
- **与三档时间尺度并列说明**：
  - 默认主图视野：**H = 5**（短期，与命中标签一致）；
  - 可选第二图或切换：**H = 20**（与中期 `mid_term_score` 命中标签一致）；
  - **长期档不出概率路径图**（配置向，见 `LONG-TERM-OUTLOOK.md`）。

### 2.2 不做什么（反模式，写进图例）

| 反模式 | 原因 |
|--------|------|
| 对外 KPI =「路径猜中率」 | `DECISION-QUALITY.md`：KPI 是门禁 + 仓位 + 可信度 |
| 红档仍给强烈方向结论 | 须与 `resolveOperationalAdvice` 一致：可展示图，文案降级 |
| LLM 编造未来点位画线 | 破坏可审计；情景叙述可保留在 MD，不进主图数值 |
| 全样本调参后画样本内路径 | 须标注样本量；后续 walk-forward 版另开 v1.1 |
| 自然日连续外推 | 必须用 **交易日** 与 `forwardReturn` 对齐 |

### 2.3 架构落点

```
Signals   → 构造历史样本路径、算分位带（prob-path-forecast.ts）
Gates     → 样本不足 / 红档 / 金价陈旧 → 降级展示规则
Portfolio → 本功能 **不直接改仓位**（可选：读 P90 跌幅做 Explain 风险提示句，v1 可不做）
Explain   → SVG/ Web 面板、meta sidecar、CLI `path` 命令
```

## 3. 概率分布折线图 — 精确定义

### 3.1 图形结构（v1 默认）

```
累计涨跌 %
   ^
   |     .......... P90 ─── 上沿折线
   |    ／‾‾‾‾‾‾‾‾  P50 ─── 中位折线（主参考）
   |   ／ ░░░░░░░░  填充：P10–P90 或 P25–P75
   |  ／  ───────── P10 ─── 下沿折线
0% ┼──●────────────────────→ 未来交易日 H
   |  ╲
   |   ╲──── 历史 60 日累计 % 实线（灰色，H<0）
```

- **历史段**：最近 **60** 个有效 `london_close`，每日相对「历史段起点」的累计 %。
- **未来段**：从 **0%**（今天收盘）起，对每个 `h = 1..H`：
  - 收集每条历史样本路径在 **第 h 个交易日** 的 **累计收益 %**（相对决策日收盘）；
  - 计算 **P10、P50、P90**（v1 固定三分位，可配置）；
  - 折线连接 `(h, Pk)` 各点。

这是 **「沿时间的分位数折线」**，不是每个 h 画一张静态概率密度图（后者 v1 不做；若用户要「钟形曲线」见 §7 待决）。

### 3.2 纵轴：为什么是「累计 %」

- 与校准、命中率、`forward-return` **同一会计起点**（报告日收盘 → T 日后收盘）。
- 用户关心的「涨了多少 / 跌了多少」一眼可读。
- 可在图侧标注 **结构位 %**：例如「P90 路径约 +4.2%，距布林上轨 +3.8%」。

### 3.3 「概率」从哪来

**条件分布**：在给定「今天」的条件下，用历史上 **相似情境** 的实走路径作为样本。

| 层级 | 条件化方式 | 样本来源 | 已有模块 |
|------|----------|----------|----------|
| **A（推荐 v1 主路径）** | 评分分桶 + 宏观 regime（可选） | 所有 `analysis_reports` 落入同分桶、且事后有完整 H 日金价路径 | `score-buckets.ts`、`calibration-tearsheet.ts`、`forward-return.ts` |
| **B（增强）** | 相似日（特征余弦近邻） | `scenario_features` + 余弦 Top-K | `scenario-similarity.ts` |
| **C（兜底）** | 无条件近 2 年全体交易日 | 任意起点后 H 日路径 | 仅当 A/B 样本 < 下限 |

**每条样本路径的构造（算法约定）**：

1. 取历史决策日 `d`（一份 analysis 或等价快照日）。
2. 从 `d` 的 `london_close` 起，取之后第 `1..H` 个 **有效交易日** 收盘，算累计收益  
   `cumPct(h) = (close(d+h)/close(d) - 1) * 100`。
3. 对当前日 `d0`，筛样本集 `S`；对每个 `h`，对 `{cumPct(h) | d ∈ S}` 取分位数。

**样本量门禁**（Gates）：

| 条件 | 行为 |
|------|------|
| \|S\| ≥ 30 | 正常展示 P10/P50/P90 |
| 10 ≤ \|S\| < 30 | 展示分位 + 图例 **「样本偏少」** |
| \|S\| < 10 | 不画未来扇形，仅历史线 + 文案「待积累」 |
| 红档（无有效金价等） | 历史线可选灰显；未来扇形标注 **「仅研究，不形成操作建议」** |

### 3.4 与三情景概率的关系

- LLM **基准/上行/下行** 与统计 **P10/P50/P90** **并列**，不强行数值一致。
- 可选 Explain：用 `scenario-probability.ts` 的 `upside/downside/base` **仅作图例文字**（「历史上行情景占比 ~X%」），**不**用其改写分位数曲线（避免两套概率打架）。

## 4. 交付物（v1 大版本范围）

### 4.1 核心模块（拟）

| 模块 | 职责 |
|------|------|
| `src/utils/prob-path-forecast.ts` | 建样本集、算 `cumPct` 路径、分位序列、结构带 % |
| `src/utils/prob-path-chart.ts` | `renderProbPathSvg()`（仿 `renderPaperEquitySvg`） |
| `src/commands/path.ts` | CLI：`path` / `path --horizon 20` / `--json` / 写 `docs/goldrush-prob-path-latest.svg` |
| `report-meta` 扩展 | `probPath: { horizon, p10, p50, p90, sampleSize, condition, schemaVersion }` |
| `web/prob-path-panel.cjs` | 文章页/首页嵌入 SVG 或内联路径 |

### 4.2 用户可见输出

| 渠道 | 内容 |
|------|------|
| CLI | 终端摘要：「5 日后 P50 约 +0.8%，P10~P90：-2.1% ~ +3.4%，n=42」 |
| SVG | 历史灰线 + 三色/填充扇形 + 0% 基准线 + 样本量/条件图例 |
| MD（可选） | `## 📈 概率路径（5 日）` 缩略图 + 免责声明 |
| Web | 折叠面板「未来路径（统计）」默认可展开 |

### 4.3 测试

- 固定 fixture 金价序列 + 假报告日 → 分位数快照测试（`test/prob-path-forecast.test.ts`）。
- SVG smoke：点数、单调 h、无 NaN。

### 4.4 明确不在 v1

- 逐日 **PDF 钟形曲线** 多子图；
- 周/月线概率锥延伸到 1 年；
- 用路径分布 **直接改** `recommendPosition` 权重；
- Brier 校准图（归 **v1.1**，对齐 ROADMAP 包 G）。

## 5. 验收标准（需求完成 ≠ 编码完成）

需求对齐通过 = 以下条目产品侧签字（**2026-11-26 已确认**）：

1. **图形态**：✅ **分位扇形**：P10/P50/P90 三条未来折线 + P10–P90 阴影带 + 左侧历史累计 % 实线（§3.1）。
2. **主视野**：✅ **双视野**：**5 日主图** + **20 日可切换/副图**（对齐短/中期命中标签）。
3. **条件化**：✅ **先评分分桶，样本不足再扩相似日 Top-K**（§3.3 层 A→B 瀑布）。
4. **分位**：P10/P50/P90 固定（v1 默认；P25/P75 仅作图内辅助标注可选）。
5. **与仓位关系**：v1 **纯 Explain**，**不**改 `recommendPosition` 公式；红档/样本不足仅降级文案与图例。

编码验收（实现阶段）：

- `npm run lint` + `npm test`；
- 无 LLM 亦可出图；
- meta `schemaVersion` 与 Web 回落策略文档化。

## 7.1 样本瀑布（锁定算法）

```
当前日 overall/quant 分 → scoreBucketRange
  → 收集同桶历史报告日，每条算 cumPct(1..H)
  → 若 |S| < TARGET_SAMPLE (30):
        用 scenario_features 余弦相似日补样本（去重日期，优先已满 H 日路径）
  → 若 |S| < MIN_SAMPLE (10): 仅历史线 +「待积累」
  → 否则: 对每个 h=1..H 算 P10/P50/P90
```

## 8. 图例文案（草案，上线用）

> **概率路径（统计示意）**  
> 基于历史上与今日相近的 N 个交易日之后金价路径计算 P10/P50/P90，纵轴为相对今日收盘的累计涨跌%。  
> 非点位预测；红档/样本不足时请勿用于加仓决策。仓位以短期操作建议为准。
