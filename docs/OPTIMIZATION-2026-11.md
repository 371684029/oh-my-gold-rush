## 0. 一页结论

1. **收益/风险（最大缺口，已补）**：项目此前只有「方向命中率」，没有任何「按建议操作会怎样」的收益/回撤度量。本轮落地**纸面权益回放**（日频不重叠 + MaxDD）：近 120 日实测，策略（推荐仓位）**+1.67% / MaxDD 7.4%**，满仓持有 **-0.40% / MaxDD 18%**，固定 50% 标配 +0.38% / 9.1% —— 推荐仓位在跌市里显著压低回撤，这是「降风险」目标的直接证据。
2. **预测准确性（发现真问题）**：新增**情景概率 Brier 校准**实测：Brier 0.298 vs 气候学 0.249，**技巧分 -0.2（差于气候学）**；可靠性分桶显示预报 13% 上行时实际涨 45%、预报 70% 时实际 46% —— LLM 情景概率目前**接近噪音**，方向命中以外的概率数字不应被当作可依赖的仓位依据（详见 §1.1）。
3. **数据有效性（补一道门禁 + 修一个回测 bug）**：门禁此前不看数据年龄，一个上周的旧报价只要数字合法就能过绿灯。本轮落地**新鲜度 SLA**（伦敦金 >48h 黄 / >96h 红；可选字段 >7 天提示）。同时发现并修复 tearsheet 权益曲线的**重叠窗口复利 bug**（见 §2.2），该 bug 会系统性放大模拟收益。

## 1. 预测准确性

### 1.1 已落地（本轮）

| 项 | 内容 | 代码 / 测试 |
|----|------|-------------|
| 情景概率 Brier 校准（ROADMAP 包 G） | `calibrate --brier`：预报上行概率 vs 5 日实际上涨频率；Brier + 气候学基准 + 技巧分 + 可靠性分桶 | `src/utils/scenario-brier.ts` · `test/scenario-brier.test.ts` |

**实测读数（2026-11-06，n=89，120 日窗）**：

| 预报上行概率 | 样本 | 预报均值 | 实际上涨频率 |
|--------------|------|----------|--------------|
| 0–20% | 20 | 13.2% | **45.0%** |
| 20–40% | 27 | 33% | 55.6% |
| 40–60% | 18 | 50% | 33.3% |
| 60–80% | 24 | 70% | **45.8%** |

Brier 0.2981 > 气候学 0.2485：**把情景概率整体替换成「永远报样本基率 46%」反而更准**。结论：三情景概率当前不带增量信息，但它仍是叙事结构的一部分——正确用法是**降权展示**而不是删除（见下一步）。

### 1.2 建议下一步（按性价比排序）

| # | 项 | 说明 | 优先级 |
|---|----|------|--------|
| A1 | **情景概率向气候学收缩** | 在 orchestrator 合成时把 upside 概率与历史基率混合（shrinkage，如 λ=0.5），或直接在 prompt 注入「你的情景概率历史 Brier 差于基率，请向 46% 收缩」；改后用 `--brier` 复验 | P0 |
| A2 | **校准偏移 OOS 应用**（ROADMAP 包 F 加深） | 当前 walk-forward 只在测试窗独立记账；真正要做「训练窗估偏移 → 应用到测试窗 → 再评」。`walk-forward.ts` 已有 train/test 框架，加 apply 步骤即可 | P1 |
| A3 | **Brier 进周反思** | `reflect` 周报纳入情景概率校准读数，形成「预报-复盘」闭环 | P1 |
| A4 | 中期档样本积累 | `mid_term_score` 仅 45 条、20 日标签可评估样本更少；坚持每日 analysis 自然积累，勿提前宣称 | ⏸ 等数据 |

### 1.3 观察项（暂不动手）

- 系统整体**偏乐观 10%**（分桶校准误差 LLM 22.9% / 量化 28.0%）——已有 rebuttal + 校准偏移机制，先看 A1/A2 效果再调 prompt，避免双改归因不清。
- 「红灯触发 24 次命中 0 次」：风险预警质量统计里红灯命中 0/24 值得单独核查口径（红灯日语义是「别操作」而非「预测跌」），暂列为观察，不改代码。

### 2.2 已修复（本轮，回测口径 bug）

**tearsheet 权益曲线重叠复利 bug**：旧实现把每个报告日的 5 日前瞻收益当独立区间逐日复利，报告近似日更时同一段行情被记 4–5 次账，模拟收益被系统性放大（且信号档位硬编码 55/45，违反口径单一来源规则）。已整体替换为 `paper-equity.ts` 日频引擎（见 §3.1），分桶统计部分改走 `forward-return.ts` 单一来源。

## 3. 提高买卖持收益与降低风险

### 3.1 已落地（本轮）

| 项 | 内容 | 代码 / 测试 |
|----|------|-------------|
| 纸面权益回放 + MaxDD（ROADMAP 包 B） | `calibrate --tearsheet` / `--md`：日频不重叠回放，决策日收盘 → 次日收益（无前视），未出报告日沿用上一目标仓。仓位优先用入库 `overall.positionTargetPct`（真实产品输出，含门禁/双分/波动约束），旧报告按 `scoreToBasePct((LLM+量化)/2)` 近似重建并显式标注。三条曲线：策略 vs 满仓持有 vs 固定 50% | `src/utils/paper-equity.ts` · `test/paper-equity.test.ts`（10 用例） |

**实测读数（2026-07-10 ~ 2026-11-06，119 个交易日）**：

| 策略 | 区间累计 | 最大回撤 |
|------|----------|----------|
| **策略（推荐仓位）** | **+1.67%** | **7.4%** |
| 满仓持有 | -0.40% | 18.0% |
| 固定 50% 标配 | +0.38% | 9.1% |

解读：样本期金价横盘偏跌，推荐仓位靠「低分轻仓 + 波动/回撤缩放」把回撤压到满仓的 41%，且绝对收益转正。**注意**：单一段行情不构成策略有效的统计证据（无 CI、样本仅一段），读数用于观察纪律是否执行，不是业绩承诺。

### 3.2 建议下一步

| # | 项 | 说明 | 优先级 |
|---|----|------|--------|
| R1 | **纸面权益进日常视野** | 周日 `digest --md` 附带近 90 日纸面权益摘要（复用 `buildPaperEquity`，纯本地零成本） | P1 |
| R2 | **换手率观测** | 回放已产出逐日仓位，加「日均仓位变动 pp」指标；若 >8pp 说明建议跳动大，反哺 `POSITION_MAX_DAILY_DELTA` 调参 | P2 |
| R3 | **回撤刹车与波动缩放参数复盘** | `volToScalar`/`drawdownToScalar` 阈值目前是经验值；积累两段以上行情后用纸面权益做敏感性对照 | ⏸ 等数据 |
| R4 | 再平衡带（偏离目标仓 >15% 才提示） | 投顾 IPS 思维，ROADMAP §2.3 已规划 | P2 |

## 4. 反模式（明确不做）

| 方向 | 原因 |
|------|------|
| 按短期命中率动态调 LLM/量化权重 | 双分政策：冲突应弃权收紧，不是抬某一侧 |
| 以点位/收益率为对外 KPI | 近随机游走；KPI 是纪律（仓位上限、门禁、弃权）与风险数字 |
| 给情景概率上量化权重 | 本轮实测 Brier 差于气候学，先收缩展示（A1），不加权 |
| 高频/套利指标、HMM/深度学习择时 | 与定投路径、样本量、项目立意不匹配 |
