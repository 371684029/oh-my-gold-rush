# GoldRush v2.5 规划文档：消息面真伪甄别、防钓鱼证伪与预测准确率系统升级

> **目标版本号**：`v2.5.0`（承接 `v2.4.0` 18 项金融工程修复与「三基 + 五专」八维正交体系）  
> **核心目标**：**提高准确率（降低假信号/噪音误导）+ 提高专业性（机构级信息审计与跨市场证伪）**  
> **架构落点**：`Signals（B2 消息面 / S3 情绪面正交升级） → Gates（信息真伪门禁） → Portfolio（噪音日自动收缩回归基准） → Explain（可审计真伪标签与证伪依据）`

## 1. 问题诊断：为什么现有「消息面」容易拖累准确率？

在 GoldRush v2.4 中，我们完成了「三基（基本面/消息面/技术面）+ 五专（资金/政策/情绪/筹码/量化）」的框架解耦，并将 60D/1Y/2Y/5Y 的消息面权重严格归零（0%）。但在短中期（5D 权重 15%、20D 权重 5%）的实战中，消息面仍存在四大隐蔽风险：

1. **假消息污染事实层**：互联网搜索（Tavily / 财经聚合）中混杂大量自媒体小作文、旧闻翻炒与未证实传闻；原有 `source-rank.ts` 将未知来源默认评为 `B` 级，门槛过宽。
2. **钓鱼消息（放风 / 流动性猎杀）最难防范**：钓鱼消息往往**来源并不假**（如"知情人士透露"、官员试探气球、大行高位喊高目标价、局部地缘摩擦被媒体情绪化放大），目的是在关键结构位制造 FOMO 追高或恐慌割肉。若只看文本情感，模型极易在派发顶部顺着标题打高分。
3. **缺少跨市场价格证伪（Cross-Market Falsification）**：黄金是全球流动性最强的宏观资产之一，真正改变基本面的消息必然在 **10Y TIPS / 2Y 美债、美元指数 DXY、GLD 资金流与金价自身二阶反应** 上留下脚印。仅靠文本关键词判利多/利空，本质是听故事而不是看真金白银投票。
4. **缺少信息半衰期与「预期差」口径**：一条 4 天前的旧闻被反复转发时，其边际信息量已衰减殆尽；同样，“好消息”若低于市场一致预期，反而会引发暴跌。

## 2. v2.5 核心架构：消息面「四道防线 + 反向价值提取」

```
原始消息 / 事件摘录
   │
   ├─ [防线 1] 信源分级与独立交叉核验（A/B/C 分级，未知源强制降为 C 级）
   │           + 时效性校验（>72h 旧闻重炒直接标 stale_rehash 归零）
   │
   ├─ [防线 2] 文本结构识别（匿名吹风 / 标题党煽动 / 预期差 Surprise）
   │
   ├─ [防线 3] 三通道跨市场价格证伪（TIPS 变动 · DXY 变动 · 金价二阶反应 · GLD 资金流）
   │           · 利好消息 + 债汇反向 + 金价下跌 / 筹码拥挤  ==>  ⚠️ 钓鱼派发 (bait_trap)
   │           · 利空恐慌 + 实际利率下行 + 金价不跌反涨      ==>  ⚠️ 诱空错杀 (bait_trap)
   │           · A级/多B级印证 + 通道同向确认                ==>  ✅ 实证真消息 (verified_fact)
   │           · 单C级/匿名无市场响应                        ==>  🚫 噪音/谣言 (noise_filtered)
   │
   └─ [防线 4] 正交分流与半衰期衰减
               ├─ 真消息  ──▶ 按指数半衰期 (T½ = 36h) + 预期差进入 B2 消息面
               ├─ 假消息  ──▶ 权重严格置 0，不污染任何打分
               └─ 钓鱼消息 ──▶ 剥离出 B2 事实层（权重置 0），反向提取为 S3 情绪面风控警示
                              （防止追高接盘 / 提示恐慌错杀，同时在 FHS 中提高收缩系数 λ 回归基准）
```

## 3. 版本功能模块拆解（v2.5.0）

### 模块 M1：消息面真伪甄别与防钓鱼引擎（P0 — 本轮核心落地）
- **新增纯函数核心** `src/utils/news-veracity.ts` 与 Web 镜像 `web/news-veracity.cjs`（零 LLM、零 DB、100% 确定性可单测）。
- **四类标准分类标签**：
  - `verified_fact`（✅ 实证真消息）：一级官方/交易所（A 级）或 ≥2 家独立主流电讯（B 级）交叉印证，且未遭跨市场价格证伪。
  - `bait_trap`（⚠️ 疑似钓鱼/背离）：存在吹风/煽动特征或单一传闻，且与 TIPS / DXY / 金价二阶反应 / GLD 资金流显著背离（如“利好不涨反跌”或“利空不跌反涨”）。
  - `stale_rehash`（🕒 旧闻翻炒）：原始事件或发布时间超过 72 小时，强制降权归零。
  - `unconfirmed_rumor` / `noise_filtered`（🚫 噪音/未核实）：单源 C 级/未知来源且无跨市场定价响应，直接滤除。
- **半衰期衰减函数**：有效真消息权重按 $w_{\text{decay}}(t) = 2^{-t / 36\text{h}}$ 衰减，确保旧催化自然淡出。
- **正交价值分流**：
  - 修复 `orchestrator.ts` 中 B2 消息面此前混算 `0.5 * sentiment + 0.5 * fundamental` 的跨维重复问题，改为完全由 `auditNewsVeracity` 驱动；
  - 将 `bait_trap` 提取出的 `contrarianSentimentBias` 与 `baitAlert` 精准注入 **S3 情绪面**，实现“把钓鱼消息变成反向风控武器”。
- **Agent Prompt 专业化升级**：在 `SentimentAgent` 系统提示词中显式写入「A/B/C 信源纪律 + 匿名吹风警示 + 二阶市场反应核验」。

### 模块 M2：事件传导卡（Event-Transmission）防钓鱼联动（P0 — 本轮落地）
- 升级 `src/utils/event-transmission.ts`：
  - 当地缘/避险标题高涨（`geo = high`）但数字通道（`rates = headwind` 且 `dollar = headwind`）或当日金价走势反向打脸时，自动附加 `veracityStatus: 'bait_suspected'` 与可读证伪提示，阻止标题党误导操作判断。
  - Markdown 日报新增「消息真伪与防钓鱼审计」摘要行，展示真消息数、滤除噪音数与疑似钓鱼警示。

### 模块 M3：预测准确率与专业度提升（P0 落地基础 + P1/P2 深化）
1. **信息噪音自适应收缩（本轮落地）**：
   - 在 `web/forecast-engine.cjs` 中，当某日检测到 `bait_trap` 或 `unconfirmed_rumor` 时，B2 自动剔除或衰减并触发重归一，同时在短期（5D/20D）FHS 预测中适度提高经验贝叶斯收缩系数 $\lambda$（向无条件历史基准靠拢），显著减少“被假利好/钓鱼盘带偏方向”的误判。
2. **Web 预测页专业化呈现（本轮落地）**：
   - 在 `/forecast` 的 **B2 消息面** 卡片上直接渲染真伪审计徽章（`✅ 跨市场实证` / `⚠️ 疑似钓鱼背离` / `🚫 噪音已滤除`）与跨市场证伪指标；
   - 在 **S3 情绪面** 卡片上同步高亮钓鱼反向警示（防 FOMO 追高 / 防恐慌割肉）。
3. **经济日历预期差（Surprise）结构化（v2.5-P2 规划）**：
   - 接入美债 2Y/10Y 盘中瞬时跳变 + 宏观日历（CPI / PCE / 非农 / FOMC）的 `Actual vs Consensus` 标准化预期差 $z = (\text{Actual} - \text{Consensus}) / \sigma_{\text{hist}}$，把“消息好坏”升级为可量化计分的“超预期幅度”。
4. **Walk-Forward 样本外准确率闭环（v2.5-P2 规划）**：
   - 新增 `calibrate --news-audit` 命令：按 `verified_fact` / `bait_trap` / `noise_filtered` 分组统计消息出现后 T+1、T+5 的实际金价收益与命中率（带 HAC 修正 Wilson 95% 区间与 Brier Skill Score），用实证数据检验防钓鱼滤网带来的真实胜率提升。
5. **分体制（Regime-Aware）动态特征核优化（v2.5-P3 规划）**：
   - 在 5D/20D 相似历史检索中，根据当前所处宏观体制（高实际利率紧缩 vs 降息周期 vs 滞胀避险）通过样本外滚动交叉验证自动微调特征距离核权重，避免牛熊切换期沿用过期因子权重；同时引入分位数 CRPS（Continuous Ranked Probability Score）评估整条概率扇面（P10–P90）的校准度，而不只看单一中位数方向。

## 5. 不变铁律（延续 AGENTS.md）
- **宁缺毋滥**：无可靠 A/B 级消息时 B2 保持缺数/中性并由其他维度重归一，绝不拿小作文凑数。
- **不以情绪改长周期**：任何突发消息（无论多真）在 60D / 1Y / 2Y / 5Y 视野中权重恒为 `0%`。
- **仓位防火墙**：单条消息永不直接越过双打分与门禁修改目标仓位，仅通过可审计的 B2 事实层与 S3 反向风控层起作用。
